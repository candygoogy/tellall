Every file says more than you think.

tellall shows what an image or copied text gives away, in plain sentences, and makes a clean copy. It all happens on your device.

    An AI image carries a signed label.

    ChatGPT and Gemini put a signed label inside the images they make. tellall reads it and says who signed it, which tool made the image, when, and what the label says about the pixels. It reports what the label says and never rules on the image.

    Who signed it

    The label carries a certificate. tellall names who it was issued to and checks that the signature still matches the file.

    What made it, and when

    The label lists each step the image went through, often with the exact time it happened.

    What it says about the pixels

    When the label states an invisible watermark, tellall repeats it and adds that a clean copy can't remove it.

    Copied text can hide characters.

    They don't show on screen, but they travel with what you paste. tellall marks each one and copies the text back without them.

      What a formatted copy holds

      Formatted copies can carry the page's address into apps like Word and OneNote; Copy clean text copies plain text only.

      A clean copy drops what's about you.

      Location, camera, dates, names and IDs go. The AI label stays, and the picture data stays byte for byte. Removing a label is a separate step, only in the command line, for files you own.

          npx tellall <file|dir|->
          Plain-sentence report. Use - to read text from stdin. Node 20.19 or later.
          
          
          --json
          Machine-readable reports
          
          
          --all
          Also print raw fields
          
          
          --fail-on private|label|any
          Exit 1 if any input has that kind of finding, for CI. Exit 0 is done, 2 a usage, read or write error.
          
          
          clean <file|dir>
          Write clean copies next to each file as name.clean.ext, never touching originals
          
          
          --remove-labels
          Also remove AI labels, on files you own
